# Crew Mission · этап A

`/game/[code]` открывает локальную демонстрацию карты космической станции. В ней четыре комнаты, три NPC, камера, схема станции и управление клавиатурой или сенсорными кнопками.

## Локальный запуск

1. Из корня frontend выполните `npm install`.
2. Скопируйте `.env.example` в `.env.local` (`Copy-Item .env.example .env.local` в PowerShell). Переменные API и WebSocket принадлежат общему каркасу, игровая демонстрация их не использует.
3. Выполните `npm run dev` и откройте [http://localhost:3000/game/ABC123](http://localhost:3000/game/ABC123). Любой код в URL открывает демо. При сохранённой гостевой сессии HUD берёт из неё никнейм.
4. Управляйте персонажем через WASD, стрелки или D-pad. Кнопка «Пауза» и Escape переключают `demo` ↔ `paused`, «В меню» открывает главную страницу. При повторном входе позиция сбрасывается.

## Устройство модуля

- `engine/map-config.ts` содержит карту 1600×900, зоны, проходы, геометрию стен, точки появления и будущие задания.
- `engine/{movement,collision,camera,input}.ts` содержат функции, которые работают без DOM. Движение со скоростью 150 px/s ограничено hitbox 28×28. Шаг одной итерации ограничен 50 мс.
- `engine/render-world.ts` рисует Canvas 2D. Геометрия препятствий используется и при отрисовке, и в физике. Неподвижная карта подготовлена на отдельном Canvas. Игровой цикл меняет позицию через ref, HUD обновляет React только при изменении зоны, паузы или гостевого имени.
- `hooks/useGameInput.ts` собирает ввод. `GameCanvas` владеет игровым циклом и ResizeObserver. При уходе с маршрута подписки и цикл снимаются.
- `GameScreen` выбирает локальную фазу. На этапе B входящий `game.snapshot` можно преобразовать в список `PlayerVisualState` и передать в рендер. Обработка снапшотов и отправка команд будут отдельным источником состояния и не потребуют переноса HUD или геометрии.

Столы и отсеки на карте служат препятствиями. Задания, Kill, Report, встречи и голосования пока недоступны. Демо не создаёт серверный матч и не устанавливает WebSocket-соединение.

## Проверки

```sh
npm run typecheck
npm run lint
npm run build
npm exec -- tsc --module commonjs --target es2020 --moduleResolution node --skipLibCheck --esModuleInterop --outDir .next/game-tests src/features/game/engine/engine.test.ts
node --test .next/game-tests/engine.test.js
```

Тесты покрывают движение при разной частоте кадров, диагональ, длинный кадр, столкновения, проходимость карты, камеру и совмещение источников ввода. Для проверки интерфейса откройте 1366×768 и 390×844, пройдите между комнатами, удерживайте D-pad, измените размер окна, поставьте демо на паузу и вернитесь в игру после выхода в меню.
